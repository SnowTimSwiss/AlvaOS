### Phase 2: Btrfs Pool Creation & Subvolume Management ✅

#### **Backend Implementation**
- ✅ **Pool Creation API** (`POST /api/v1/storage/pools`)
  - Accepts pool name, device list, RAID level
  - Validates RAID requirements (RAID1 needs 2+ disks, RAID10 needs 4+)
  - Executes `mkfs.btrfs` with appropriate flags
  - Auto-mounts pool at `/mnt/alvaos/{pool_name}`
  - Persists pool state to `/var/lib/alvaos/pools.json`

- ✅ **Pool Listing API** (`GET /api/v1/storage/pools`)
  - Parses `btrfs filesystem show` output
  - Extracts pool UUID, label, devices
  - Gets usage info with `btrfs filesystem usage`
  - Detects RAID level from metadata

- ✅ **Pool Deletion API** (`DELETE /api/v1/storage/pools`)
  - Unmounts pool safely
  - Removes mount point
  - Updates state file
  - **Does NOT erase data** - pool can be recreated

- ✅ **Subvolume Management APIs** (`/api/v1/storage/pools/<pool_id>/subvolumes`)
  - **GET**: List all subvolumes in a pool
  - **POST**: Create new subvolume
  - **DELETE**: Delete subvolume (with data)

## 💡 Usage Examples

### Creating a RAID1 Pool
1. Navigate to Storage → Pools tab
2. Click "Create Pool"
3. Enter pool name (e.g., "data-pool")
4. Select 2 or more disks
5. Choose "RAID1 (Mirroring)"
6. Click "Create Pool"
7. Confirm the warning
8. Pool is created and mounted at `/mnt/alvaos/data-pool`

### Creating a Subvolume
1. Click "Manage Subvolumes" on a pool card
2. Enter subvolume name (e.g., "documents")
3. Click "Create"
4. Subvolume is created at `/mnt/alvaos/data-pool/documents`

### Deleting a Pool
1. Click "Delete Pool" on a pool card
2. Confirm deletion
3. Pool is unmounted
4. Data is preserved on disks
5. Pool can be recreated later if needed

## 🔧 System Requirements

### Required Packages
```bash
sudo apt-get install -y btrfs-progs
```

### Sudo Permissions
The backend needs sudo access for:
- `mkfs.btrfs` - Pool creation
- `btrfs` commands - Pool and subvolume management
- `mount` / `umount` - Mounting/unmounting pools

### Recommended Setup
- At least 2 unused disks for testing RAID1
- 4 unused disks for testing RAID10
- Disks should not contain important data (will be erased)
